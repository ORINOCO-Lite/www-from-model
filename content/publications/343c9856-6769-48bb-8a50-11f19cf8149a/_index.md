    analytic techniques . This includes functional alignment, inter-subject correlations,
    inter-subject representational similarity analysis, inter-subject functional connectivity,
    event segmentation, natural language processing, hidden semi-markov models, automated
    annotation extraction, and visualizing high dimensional data. The tutorials focus
    on practical applications using open access data, short open access video lectures,

    from the python scientific computing community (e.g., numpy, pandas, scipy, matplotlib,
    scikit-learn, networkx, nibabel, nilearn, brainiak, hypertoos, timecorr, pliers,
    statesegmentation, and nltools). The course is designed to be useful for varying
    levels of experience, including individuals with minimal experience with programming,
    Python, and statistics.
