    \ in NifTi format for each hemisphere in the reference space. The Julich-Brain atlas\
    \ relies on a modular, flexible and adaptive framework containing workflows to create\
    \ the probabilistic brain maps for these structures. Note that methodological improvements\
    \ and updated probability estimates for new brain structures may in some cases lead\
    \ to measurable but negligible deviations of existing probability maps, as compared\
    \ to earlier released datasets. Other available data versions of Area p24ab (pACC):\
