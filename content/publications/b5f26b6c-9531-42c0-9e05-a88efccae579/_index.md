    \ mesial SFG) is provided in the NifTi format for each brain reference space and\
    \ hemisphere. The Julich-Brain atlas relies on a modular, flexible and adaptive\
    \ framework containing workflows to create the probabilistic brain maps for these\
    \ structures. Note that methodological improvements and integration of new brain\
    \ structures may lead to small deviations in earlier released datasets. Other available\
    \ data versions of Area 6ma (preSMA, mesial SFG): Ruan et al. (2019) [Data set,\
